# O_CAR 智能车工程

## 项目简介
基于英飞凌 TC264 单片机的智能车竞赛/项目工程。

## 硬件平台
- 主控：英飞凌 TC264
- 开发环境：Tasking / ADS

## 功能模块
本仓库 `code/` 目录下包含以下功能模块：

| 文件 | 功能说明 |
|------|---------|
| `Pid.c` | PID 控制算法 |
| `Kalman.c` | 卡尔曼滤波 |
| `Balance.c` | 平衡控制 |
| `Brushless.c` | 无刷电机驱动 |
| `729_camera.c` | 摄像头图像采集 |
| `ADC.c` | ADC 采集 |
| `Init.c` | 外设初始化 |
| `Menu.c` | 菜单交互 |
| `KEY.c` | 按键输入 |
| `Led.c` | LED 指示灯 |
| `Siyuansu.c` | 思元素模块 |

## 依赖库
本工程依赖以下官方库，需自行下载后加入工程：
- 英飞凌 iLLD 库（TC264）
- 逐飞库（zf_common / zf_device）

## 使用方法
1. 搭建 TC264 开发环境
2. 下载并配置上述依赖库
3. 将本仓库 `code/` 目录下的文件加入工程
4. 参考根目录下的 `推荐IO分配.txt` 完成硬件接线

## 硬件接线说明
详见 `推荐IO分配.txt` 和 `尽量不要使用的引脚.txt`
